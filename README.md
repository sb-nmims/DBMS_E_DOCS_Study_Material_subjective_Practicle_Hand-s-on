Database Management System (DBMS) – E-Content

Welcome to the E-content repository for the Database Management System (DBMS) course offered by the Computer Engineering Department, Mukesh Patel School of Technology Management and Engineering (MPSTME), SVKM's NMIMS.

This repository contains unit-wise lecture materials and laboratory resources to support students in understanding the theoretical concepts and practical implementation of Database Management Systems.

📚 Course Information
Course: Database Management System (DBMS)
Course Code: 702A10C027
Credits: 3
Academic Year: 2025–26
Department: Computer Engineering
Program: B.Tech / MBA Tech / B.Tech Integrated
Course Faculty:Dr. Sachin Bhandari and other course faculty members

The course focuses on database concepts, relational databases, SQL, database design, normalization, transactions, concurrency, and NoSQL databases.

🎯 Course Outcomes

After successful completion of the course, students will be able to:

Describe core concepts of databases and model a database management system using ER modelling.
Apply relational algebra and SQL to retrieve and manage data from relational databases.
Demonstrate the use of normalization for database design.
Demonstrate transaction concepts and use modern database techniques such as NoSQL.
